# Exercícios de Programação Orientada a Objetos (POO)

Repositório com implementações em **Java**, explorando conceitos fundamentais de POO.  
O objetivo é praticar e consolidar conhecimentos adquiridos em sala de aula.

## Conteúdos abordados
- Herança
- Polimorfismo
- Encapsulamento
- Classes e objetos

## Tecnologias
- Java
